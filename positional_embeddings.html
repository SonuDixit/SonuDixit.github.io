01 · One position axis

RoPE: encode relative sequence position

Rotary Position Embedding (RoPE) rotates each 2D pair in a query or key vector by an angle determined by the token's sequence position. Different pairs use different frequencies.

q̃ₚ = R(p)q    k̃ₛ = R(s)k
q̃ₚᵀk̃ₛ = qᵀR(s − p)k
The positional part of the attention score depends on the relative offset (s − p), while the content vectors q and k still matter.

One sequence, one position index

A 2 × 3 × 4 visual grid flattened into a sequence would assign each patch one scalar index.

Flattening makes the relative sequence offset explicit, but the scalar index alone does not say whether two image patches differ by row, column, or frame.

02 · Three position axes

MRoPE: distinguish time, height, and width

Multimodal RoPE (MRoPE), introduced in Qwen2-VL, gives visual tokens a position triple (t, h, w). The rotation math is still RoPE; each rotary-frequency section selects one coordinate from the triple.

For this toy example, each rp has 8 frequency entries (the half-dimensional frequency tensor). Slices are half-open: [0:2] selects entries 0–1, [2:5] selects 2–4, and [5:8] selects 5–7. The model then duplicates selected frequency coefficients to match the full head dimension; cosine and sine coefficients together implement the rotation.

In this worked example, T selects entries 0–1 from r₀, H selects entries 2–4 from r₁, and W selects entries 5–7 from r₂. The [2, 3, 3] split is for visualization only; production models use their own section sizes and coefficient layouts.

What MRoPE adds: moving one patch to the right changes the W position but not T or H; moving down changes H; moving to another frame changes T. This preserves axis-specific relative-position information instead of expressing all offsets through one flattened index.
03 · Frequency allocation

Interleaved MRoPE: distribute frequencies across axes

Qwen3-VL's Interleaved MRoPE changes how frequency entries are assigned to T, H, and W. Rather than giving each axis a single contiguous band, it interleaves axis assignments across the spectrum, so each axis receives frequencies from multiple scales.

The motivation is a more balanced frequency spectrum per axis. In chunked MRoPE, an axis may get only high-, mid-, or low-frequency entries; interleaving spreads its entries across a broader range of rotary frequencies. This is intended to improve spatial-temporal modeling, particularly for long videos.

Implementation detail: Qwen3-VL's default `mrope_section = [24, 20, 20]` describes counts in the half-dimensional frequency tensor (64 entries for a 128-dimensional head), not scalar dimensions. Its implementation interleaves T/H/W with model-specific section lengths, so the real pattern is not a perfectly repeating cycle at the end: the remaining frequency slots are retained by the temporal stream.

Interleaving does not change the RoPE rotation identity and does not guarantee a higher attention score. It changes the frequencies available to each positional axis.

Takeaways

RoPE

Position enters attention through rotations; the composition property gives a relative offset.

MRoPE

Visual tokens use separate temporal, height, and width coordinates, each controlling its assigned rotary frequencies.

Interleaved MRoPE

Changes the assignment of frequency entries, spreading each axis across the spectrum rather than giving it one contiguous band.

Important caveat

Neither method guarantees higher attention to nearby patches. They define positional structure; learned Q/K content determines the final score.
